### **Модуль 2: Введение в CSS (Лабораторная работа №2) — Освоено**

1.  **Основы CSS:**
    *   **Синтаксис:** Полное понимание структуры правила: **селектор { свойство: значение; }**.
    *   **Подключение:** Умение создавать внешний файл `styles.css` и подключать его к HTML через `<link>`.

2.  **Ключевые концепции и навыки:**
    *   **Box Model (Блочная модель):** На практике освоил разницу между внешними отступами (`margin`) для позиционирования блоков и внутренними (`padding`) для создания "воздуха" внутри них.
    *   **Display (Поведение элементов):** Глубокое понимание разницы между **блочными** и **строчными** элементами. Успешно применил `display: block` для изменения поведения `<a>` и `<img>`.
    *   **Центрирование:** Освоил два основных метода центрирования:
        *   `text-align: center` для текста и строчных элементов.
        *   `margin: 0 auto` для блочных элементов с заданной шириной.

3.  **Примененные свойства и техники:**
    *   **Фон:** Стилизация фона с помощью `background-image: linear-gradient()`.
    *   **Шрифты и текст:** `font-family`, `font-size`, `text-align`.
    *   **Лейаут и размеры:** `max-width`, `min-height` (включая единицы `vh`).
    *   **Стилизация списков:** `list-style-position`.
    *   **Стилизация таблиц:** `border`, `border-collapse`.

4.  **Навыки отладки (Debugging):**
    *   **Решение проблемы "повторяющегося фона":** Самостоятельно обнаружил и исправил проблему с высотой `<body>` и повторением градиента с помощью `min-height: 100vh` и `background-repeat: no-repeat`.
    *   **Сброс стилей браузера:** Понял необходимость обнуления стилей по умолчанию (`margin: 0` на `body`) для предсказуемого центрирования.
    *   **Использование инструментов разработчика (F12):** Продемонстрировал умение инспектировать элементы для диагностики проблем с отступами (`margin`/`padding`).
    *   **Валидация CSS:** Научился использовать правильный валидатор W3C для CSS.
